# 数据中台产品原型

这是一个不连接后端的静态交互原型，用于验证第一版信息架构和业务流程。

直接双击 `index.html`，或在仓库根目录运行：

```bash
python -m http.server 4173 --directory prototype
```

然后访问 <http://localhost:4173>。

原型包括：

- 数据中台总览；
- Skill 新建、搜索、状态筛选与数据能力绑定；
- Reference 目录创建、文档上传、筛选、排序、详情和失败重试；
- 统一 KOC 达人库、表格导入、结构化筛选和达人详情；
- 抖音、小红书平台切换、品牌与趋势洞察能力绑定、五类热点指标和品牌 GEO 搜索；
- 导入记录、详情弹窗和 MCP 调用示例。
- 13 个第一版业务接口契约：1 个 Reference、1 个 KOC、10 个热点指标和 1 个品牌 GEO 接口。

接口目录明确展示 MCP Tool、REST API、入参、请求示例和响应示例。运营后台 CRUD 不计入这 13 个 MCP 业务查询接口。

页面数据均为演示数据，不代表实际接口或最终视觉稿。
